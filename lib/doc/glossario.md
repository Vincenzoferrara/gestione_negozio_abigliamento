# Glossario

- `MGWS` - backend proprietario per inventario e logica esterna
- `WooCommerce` - backend e-commerce usato per le funzioni native
- `Barcode interno` - codice prodotto interno all'app (ex "SKU"); corrisponde al campo tecnico WooCommerce/CSV `sku` e al prefisso QR `SKU:`
- `Barcode fornitore` - codice prodotto del fornitore (ex "SKU fornitore"); corrisponde al campo tecnico `supplier_sku` dei payload MGWS/metadati
- `Barcode` - codice a barre del produttore (GTIN/UPC/EAN/ISBN); resta il campo tecnico `barcode` dei metadati
- `JWT` - metodo di autenticazione basato su token
- `Smartcard` - accesso con NFC o lettore USB
- `Docking` - layout desktop a schede
- `Singleton` - pagina riusabile in una sola istanza
- `Duplicate` - pagina apribile in piu istanze
