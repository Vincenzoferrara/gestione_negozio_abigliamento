# Glossary

- **MGWS** - MG Warehouse Stock, the WordPress plugin that provides operational stock, POS, loyalty, employee and reporting APIs.
- **WooCommerce** - the e-commerce engine used for products, orders, coupons and customers.
- **POS / Cashier** - point-of-sale workflow used for in-store sales.
- **Cash shift** - local POS work session used to group receipts and closure operations.
- **Movement ledger** - append-only MGWS history of stock operations.
- **Reconcile stock** - operation that sets stock to the counted final value.
- **Move stock** - operation that transfers stock between locations without changing total quantity.
- **Supplier** - MGWS business entity used by purchasing and receiving workflows.
- **Loyalty card** - MGWS card linked to a loyalty account and points ledger.
- **DataGridView** - shared table component used by operational lists.
- **Velopack** - desktop update system used by Windows and Linux builds.
